# 🏝️ GrowGo: Mist Island

A cozy exploration mini-game developed as part of the **GrowGo** project, set on a mysterious island filled with hidden secrets.

## ✨ Key Features
* **🔍 Magnifying Glass Inspection:** Drag the magnifying glass across the island environment to reveal hidden items, secret clues, and Easter eggs tucked away in the fog.
* **🌫️ Cozy Atmospheric Vibe:** Designed with a relaxing and immersive aesthetic, blending exploration mechanics with a mysterious island setting.
* **🧩 Environmental Puzzles:** Use inspected items and discovered clues to solve riddles and progress through the game journey.

## 🛠️ Tools & Tech Stack
* **Game Engine / Language:** Unity, C#
* **Design & UI/UX:** Figma (User Flows, Wireframing, and UI Prototyping)
* **Version Control:** Git & GitHub
